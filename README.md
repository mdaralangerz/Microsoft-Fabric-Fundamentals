# Microsoft Fabric Fundamentals: step-by-step guides

Step-by-step PowerPoint guides for the **Microsoft Fabric Fundamentals** video series on the
[Data Engineering with Lunak](https://www.youtube.com/@LunakData) YouTube channel.

**56 videos** so far: a Start here video and 55 tutorials in 9 groups. Each video has a matching guide, free to download from the **[Fundamentals guides folder on Google Drive](https://drive.google.com/drive/folders/1LnlKjQHa0pv4QhBlLQBjMyYE54B6Yqxp)**. The guide has a screenshot of every screen, the exact control to select and
what you should see next, so you can follow along in your own Fabric workspace without pausing the video.

## How to use the guides

1. **Open the [Fundamentals guides folder](https://drive.google.com/drive/folders/1LnlKjQHa0pv4QhBlLQBjMyYE54B6Yqxp)** on Google Drive. You don't need a Google account.
2. **Open your group's folder.** The guides are grouped like the series: `g00-start-here`, `g01-getting-started`,
   `g02-data-lifecycle`, and so on up to `g09-devops-monitoring`. Each file starts with the video's number, so
   `001_What_is_Microsoft_Fabric.pptx` goes with video 001. Exercise files (`…_Exercise_Files.zip`) are in the same
   group folder: unzip them before you start.
3. **Download the guide.** Select the file, then **Download** (the down arrow at the top right of the preview).
4. **Open it** in PowerPoint, Google Slides or Keynote, and read **"Before you start"** first. It lists what you
   need, such as a Fabric trial or capacity.
5. **Follow one slide at a time.** Each slide is one action: where the control is, what to select, and what you
   should see next.

## What you need

- A Microsoft Fabric account. A free 60-day trial works: videos 003 and 004 show how to start one, including with
  a personal email.
- A web browser. Most videos need nothing else.
- For a few videos, the guide's **"Before you start"** slide lists extra tools or roles: for example Power BI Desktop
  (043, 044), a free Azure DevOps organization (050), or the Fabric administrator role for tenant settings.
