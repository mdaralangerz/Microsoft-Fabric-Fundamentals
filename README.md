[Data Engineering with Lunak](https://www.youtube.com/@LunakData) YouTube channel.

Each video has a matching guide. The guide has a screenshot of every screen, the exact control to select and
what you should see next, so you can follow along in your own Fabric workspace without pausing the video.

## How to use the guides

1. **Download a guide.** Select its file name in the table above, then **Download raw file** (the download icon at
   the top right of the file view).
2. **Open it** in PowerPoint, Google Slides or Keynote.
3. **Read "Before you start" first.** It lists what you need, such as a Fabric trial or capacity.
4. **Follow one slide at a time.** Each slide is one action: where the control is, what to select, and what you
   should see next.

## What you need

- A Microsoft Fabric account. A free 60-day trial works: videos 003 and 004 show how to start one, including with
  a personal email.
- A web browser. There's nothing to install.
